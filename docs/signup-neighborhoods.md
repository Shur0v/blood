# Signup and service-location neighbourhoods

The account location workflow is documented in [Location Management and countrywide search](location-management.md).

The administrator dashboard now controls detailed selection, countrywide/district scope, nearby priority, spelling suggestions and labels. Existing environment flags initialize the detail setting on first use. Database settings control subsequent changes.

Existing neighbourhood records, service-city limits and removal deadlines are preserved. Select a verified suggestion to add or update a location.
