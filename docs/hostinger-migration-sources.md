# Provider migration references

Reviewed 26 October 2026, Asia/Dhaka. Provider interfaces and eligibility can change. The Platform Guide explains BloodNet's PostgreSQL/Node/PM2 process; generic MySQL commands in provider articles are not BloodNet restore commands.

- VPS migration: https://www.hostinger.com/support/2774885-how-to-migrate-your-vps-to-hostinger/
- Move services between accounts: https://www.hostinger.com/support/1583284-how-to-move-services-from-one-hostinger-account-to-another/
- Domain ownership move: https://www.hostinger.com/support/4068055-how-to-move-a-domain-between-hostinger-accounts/
- Registrar transfer: https://www.hostinger.com/support/1583436-how-to-transfer-a-domain-to-hostinger/

A domain ownership transfer does not migrate application files, database or mail. Keeping the current domain/DNS account while repointing a domain is a separate option. Check the provider's current eligibility and verification requirements at execution time.
