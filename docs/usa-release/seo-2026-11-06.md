# USA SEO follow-up — 6 November 2026

## Changes

- Fourteen curated guides now have location-specific donor-directory metadata and descriptive default headings. City/state context belongs to the reviewed area registry; legacy directories do not guess states from city names.
- USA country sharing/search metadata and existing USA city/group/country-qualified metadata describe actual directory functions. Existing routes, canonicals, indexing gates, donor ordering and publication settings remain intact.
- Curated orientation sections include visible, server-rendered local questions, FDA donation-process guidance and related coordination/private-profile links. The twenty/twelve-section compositions are retained.
- USA default introduction copy distinguishes contacts and listings from confirmed availability. Organization-inclusive totals are labelled as directory entries; organ pledges are not described as allocations or confirmed clinical matches.
- Collection-page schema describes the directory's actual subjects and publisher. No hospital credentials, FAQ rich-result promises, keyword stuffing, hidden keyword text or clinical endorsements are introduced.

Published administrator copy still takes precedence and must be reviewed by its owner. This release does not bulk rewrite stored editorial content or publish drafts.
