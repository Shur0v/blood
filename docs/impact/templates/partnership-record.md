# Partnership evidence template — restricted when completed

This blank template is public. Keep completed records and correspondence outside Git in restricted storage. Do not publish a partner name/logo or imply endorsement without permission.

## Record

- Internal reference / record date / reviewer: [values]
- Organisation and authorized representative: [restricted details; verify authority]
- Status: [outreach lead / informal collaboration / confirmed agreement / ended]
- Agreed activity and geographic scope: [specific work, responsibilities and limits]
- Start / review / end date, if agreed: [values; no invented commitment]
- Confirmation source: [dated agreement or authorized correspondence reference]
- Verification performed / outstanding questions: [facts]

## Publication and data boundaries

- Permission to name the organisation publicly: [yes/no; source/date]
- Permission for logo, quotation or case study: [separate permissions]
- Data exchange: [none or precisely agreed categories, purpose and authorization]
- Approved public wording: [exact wording or no public claim authorized]
- Retention, access owner and next review: [document decisions before collection]
- Correction/withdrawal route: [agreed private channel]

No donor/patient list, medical report or prescription belongs in this record. An outreach email is not a partnership; a partnership is not evidence that a donation occurred. Public monthly reports should include only confirmed, approved information with a current review date.
